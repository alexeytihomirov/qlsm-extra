# host-metrics addon: per-host and per-instance resource dashboard with capacity verdict

## Цель

Аддон qlsm с дашбордом потребления ресурсов по каждому хосту и инстансу, историей за 30 дней и журналом событий. По нему оператор должен видеть, хватает ли железа и сколько ещё инстансов влезет на хост.

## Контекст

Схема согласована с оператором 2026-10-15:

- **Ядро qlsm не меняем.** У ядра нет планировщика для аддонов: поллер не вызывает аддоны, а нить в `register()` задвоится в каждом процессе. Своих таблиц в БД у аддона нет, есть только `AddonState`. Поэтому историю храним на самом хосте.
- **Сеть только на вытягивание** (`docs/policies/ops.md`): хост ничего не отправляет домой, qlsm забирает данные по SSH.
- **Сборщик на хосте.** systemd timer, ставится плейбуком через хук `host.setup`, образец `qlsm-extra/addons/file-forwarder/`. Пишет в локальный SQLite:
  - хост: CPU по ядрам, steal, load, RAM, swap, диск, сеть (байты и пакеты);
  - каждый `qlds@<port>.service`: CPU и RAM по его cgroup, число игроков из локального Redis (ключи serverchecker).
  - Хранение: 48 ч в полном разрешении, 30 дней в минутных средних.
- **Журнал событий.** Ядро под 100%, всплески steal, OOM, нехватка диска, события `ql-watchdog` (`/var/lib/qlsm/watchdog/events.jsonl`).
- **Бэкенд аддона.** Забирает срез по SSH, только когда открыт дашборд.
- **UI tier-2.**
  - Страница `page` со сводкой по всем хостам. Пункта в навбаре нет, вход со страницы Addons.
  - Окно в `host_menu` с графиками по хосту и его инстансам.
  - Вывод о запасе. QLDS работает в один поток, поэтому сравниваем пиковый CPU инстанса под нагрузкой со свободными ядрами и steal.
- **Время кадра сервера** считает плагин minqlx на хуке `frame` (вопрос оператора 2026-10-15). Плагин копит статистику интервалов между кадрами, а сброс делает раз в N секунд вне игрового потока.
- Связано с `root-0020`: на подаренных VPS нужен реальный steal до раскладки инстансов.

3. Открыть карточку (Details): сводка текстом сверху, над каждым графиком строка вывода, пунктирные пороги, подсказки в легенде.
4. Колокольчик в навбаре: пуст, пока на хостах нет проблем.
5. Сыграть матч на GermanyHetzner :27960 -> через несколько минут у хоста появится вывод о запасе (room for N).
