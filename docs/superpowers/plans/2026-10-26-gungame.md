## Global Constraints

- Import header exactly as `item_roulette.py:36-41` (`try: import minqlxtended as minqlx` / `except ImportError: import minqlx`).
- Cvars and defaults (seeded with `set_cvar_once`): `qlx_gunGameEnabled 0`, `qlx_gunGameLadder "rl:2 rg:2 lg:2 pg:2 sg:2 gl:2 mg:2 g:1"`, `qlx_gunGameGauntletDemote 1`, `qlx_gunGameSuicideDemote 1`, `qlx_gunGameStepNotify print`, `qlx_gunGameLeaderNotify print`.

- Game-thread rules (`skills/minqlx-plugin-review/SKILL.md` in the monorepo): no I/O, no threads, no redis; `item_touch` handler is one classname check.

- Commit messages in English, no AI attribution, no `Co-Authored-By`.
- Hyphens only in all texts.

## Review Focus

- Ladder cvar typos (`rl:0`, `xx:2`, `rl`, extra spaces, `hands:1`): the plugin keeps the last valid ladder and logs once; it never crashes a hook. Test: `test_invalid_ladder_keeps_previous` (Task 2).
- A player killed while their killer is already dead or disconnected (rocket in flight): the killer's state still advances, the loadout write skips a dead or gone player without an exception. Test: `test_kill_by_disconnected_killer_does_not_raise` (Task 3).
- Two players on the last step at once: the win goes to the one who frags first; their score becomes ladder length + 1, never a tie. Test: `test_win_sets_score_and_fraglimit_above_ladder` (Task 3).
- Team switch kill (`mod SWITCH_TEAMS`) and warmup deaths: no demote, no step change. Tests: `test_switch_teams_death_does_not_demote`, `test_warmup_kill_does_not_count` (Task 3).
- Plugin disabled, or the gametype is not FFA: map items stay, `item_touch` passes, spawns get stock weapons. Test: `test_disabled_or_not_ffa_is_inert` (Task 2).

```python
"""gungame: ladder parsing, step logic, texts."""
import pytest

from tests._minqlx_stub import import_plugin

pytestmark = pytest.mark.standalone

gg = import_plugin("gungame")
L3 = [("rl", 2), ("lg", 1), ("g", 1)]


def test_parse_ladder_default():
    assert gg.parse_ladder(gg.DEFAULT_LADDER) == [
        ("rl", 2), ("rg", 2), ("lg", 2), ("pg", 2), ("sg", 2), ("gl", 2), ("mg", 2), ("g", 1)]


def test_parse_ladder_accepts_hmg_bfg_and_extra_spaces():
    assert gg.parse_ladder("  hmg:3   bfg:1 ") == [("hmg", 3), ("bfg", 1)]


@pytest.mark.parametrize("bad", ["", "   ", "xx:2", "rl", "rl:", "rl:0", "rl:-1", "rl:a", "hands:1"])
def test_parse_ladder_rejects(bad):
    with pytest.raises(ValueError):
        gg.parse_ladder(bad)


def test_parse_channels():
    assert gg.parse_channels("print") == {"print"}
    assert gg.parse_channels("print,center") == {"print", "center"}
    assert gg.parse_channels(" center , junk ") == {"center"}
    assert gg.parse_channels("off") == frozenset()
    assert gg.parse_channels("") == frozenset()


def test_advance_frag_counts_then_steps_up():
    assert gg.advance((0, 0), L3, "frag") == ((0, 1), "none")
    assert gg.advance((0, 1), L3, "frag") == ((1, 0), "up")


def test_advance_frag_on_last_step_wins():
    assert gg.advance((2, 0), L3, "frag") == ((2, 1), "win")


def test_advance_demote_floor_and_reset():
    assert gg.advance((1, 0), L3, "demote") == ((0, 0), "down")
    assert gg.advance((0, 1), L3, "demote") == ((0, 0), "down")
    assert gg.advance((0, 0), L3, "demote") == ((0, 0), "none")


def test_loadout_and_weapons():
    assert gg.loadout(L3, 1) == "lg"
    held = gg.loadout_weapons("lg")
    assert len(held) == len(gg.WEAPON_FIELDS)
    assert [f for f, h in zip(gg.WEAPON_FIELDS, held) if h] == ["g", "lg"]
    assert [f for f, h in zip(gg.WEAPON_FIELDS, gg.loadout_weapons("g")) if h] == ["g"]


def test_is_blocked_item():
    assert gg.is_blocked_item("weapon_rocketlauncher")
    assert gg.is_blocked_item("item_quad")
    assert not gg.is_blocked_item("item_armor_body")
    assert not gg.is_blocked_item("item_health_mega")
    assert not gg.is_blocked_item("ammo_rockets")


def test_pick_leader_keeps_current_on_tie_and_needs_step_one():
    assert gg.pick_leader({1: (0, 1), 2: (0, 0)}, None) is None
    assert gg.pick_leader({1: (2, 0), 2: (1, 1)}, None) == 1
    assert gg.pick_leader({1: (2, 0), 2: (2, 1)}, 1) == 1
    assert gg.pick_leader({1: (2, 0), 2: (3, 0)}, 1) == 2


def test_texts():
    assert gg.step_text(L3, (1, 0)) == "Step 2/3: ^3LG^7 (0/1)"
    assert gg.demote_text(L3, (0, 0)) == "Down to step 1/3: ^3RL^7"
    assert gg.leader_text("Bob", 2, 3) == "^3Bob^7 leads: step 2/3"
    assert gg.last_step_text("Bob", "g") == "^3Bob^7 is on the last step (^3GAUNTLET^7)!"
    assert gg.win_text("Bob") == "^3Bob^7 wins Gun Game!"
```

### Task 3: Kills, deaths, leader, win

**Interfaces:**
- Consumes: Task 2 attributes and helpers.
- Produces: `handle_kill(victim, killer, mod)`, `handle_death(victim, killer, mod)`, `_finish(winner) -> None` (`@minqlx.next_frame`).

Behaviour (spec "Plugin behaviour"; nothing counts unless `_active()` and `_in_progress()`):
- `handle_kill`: killer `advance(..., "frag")`. `up` -> `_give_loadout(killer)` + `step_text` to the killer (`qlx_gunGameStepNotify`). `none` -> score write only (via `_give_loadout`, which also rewrites the score). `win` -> `_finish(killer)`. Then, if `str(mod) == "GAUNTLET"` and `qlx_gunGameGauntletDemote`, victim `advance(..., "demote")`; on `down` `demote_text` to the victim. Then leader check.
- `handle_death`: only when `killer is None` or `killer.steam_id == victim.steam_id`, `str(mod) != "SWITCH_TEAMS"`, and `qlx_gunGameSuicideDemote`: victim demote, `demote_text` on `down`, score write next frame.
- Leader check: `new = pick_leader(_states, _leader)`; if `new != _leader` and not None -> `leader_text` to everyone (`qlx_gunGameLeaderNotify`); a player reaching the last step -> `last_step_text` to everyone. Names from `player.name` (the player whose state changed; for a leader change the killer is the only one who can take the lead).
- `_finish(winner)`: `winner.score = len(_ladder) + 1`, `set_cvar("fraglimit", str(len(_ladder) + 1))`, `win_text` to everyone.
